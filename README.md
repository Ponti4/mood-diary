# 마음 일기

매일의 감정과 이유를 기록하는 개인용 로컬 웹서비스입니다. 기록은 서버로 전송되지 않고 현재 브라우저의 `localStorage`에 저장됩니다.

## 실행하기

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 열면 됩니다.

## 주요 기능

- 날짜별 감정과 100자 이내의 일기 기록
- 기록 수정 및 삭제
- 최근 7일·30일 기록과 감정별 필터
- JSON 백업 다운로드 및 병합 복원
- 모바일·데스크톱 반응형 화면

## 확인 명령

```bash
npm test
npm run build
```

브라우저 데이터를 삭제하면 기록도 함께 삭제됩니다. 중요한 기록은 설정 메뉴의 **백업 다운로드**로 보관하세요.
